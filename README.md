# Barbería Plaza Barcelona by Kamal

Website of Barbería Plaza Barcelona, Plaza de Barcelona 17, 37004 Salamanca.

Live at https://barberiaplazabarcelona.es/ (GitHub Pages, custom domain set in `CNAME`).

Single static page: `index.html` (animated hero, price list, WhatsApp appointments, map). Hero video in `hero.mp4` / `hero.webm`, storefront photo in `storefront.webp`.

Web design: [Ziad El Alami](https://elalamiz605-tech.github.io/)
